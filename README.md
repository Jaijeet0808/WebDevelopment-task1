# Simple Web Development Project

This is a beginner-level web development project built using **HTML**, **CSS**, and **JavaScript**. It was created as part of a 9-day learning task to understand and apply the basics of web technologies.

## 📄 Features

- **HTML**: Structured layout with headings, paragraphs, images, and useful links.
- **CSS**: Basic styling including fonts, colors, spacing, and layout adjustments.
- **JavaScript**: A button that shows an alert message when clicked.

## 💡 Purpose

The purpose of this project is to practice foundational web development skills and build confidence in creating and styling webpages with basic interactivity.

## 🔧 How to Run

1. Clone or download the repository.
2. Open the `index.html` file in your browser.
3. Explore the styled webpage and try clicking the button!

## 📁 Project Structure

/project-folder
│
├── index.html # Main webpage structure
├── styles.css # Styling rules
└── script.js # JavaScript interactions
